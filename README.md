# План свадьбы на 200 гостей

Одностраничный сайт: подготовка к свадьбе, обязанности, программа вечера с 17:00 до 00:00, тосты и игры. Во всех разделах можно добавлять и удалять пункты и отмечать готовность. Общий процент выполнения считается автоматически.

## Файлы

- `index.html` — весь сайт в одном файле (разметка, стили и скрипты).
- `README.md` — эта инструкция.

## Как загрузить на GitHub

1. Войдите на [github.com](https://github.com) и нажмите **New repository**.
2. Назовите репозиторий, например `wedding-plan`, выберите **Public** и нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** (или **Add file → Upload files**).
4. Перетащите `index.html` и `README.md` в окно браузера.
5. Нажмите **Commit changes**.

## Как включить сайт по ссылке (GitHub Pages)

1. В репозитории откройте **Settings → Pages**.
2. В блоке **Build and deployment** выберите **Deploy from a branch**.
3. Укажите ветку **main** и папку **/ (root)**, нажмите **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/wedding-plan/`.

## Что важно знать

- Отметки и добавленные пункты сохраняются в браузере на том устройстве, где вы их сделали. На другом телефоне или компьютере будет исходный список.
- Чтобы изменить исходные данные (список подготовки, тайминг, тосты, игры), откройте `index.html` на GitHub, нажмите значок карандаша и отредактируйте блок `seed()` в конце файла.
- Дату свадьбы можно указать на самой странице, под заголовком: сайт покажет, сколько дней осталось.
- Шрифты подгружаются с Google Fonts. Без интернета сайт работает, но с обычными системными шрифтами.
